- **Calibration no longer runs at pit power.** In v0.16 a calibration started before the drone's first arm read the pit power as the drone's reference level: under the flat pit index the radio reports that index as its reference. The whole run was then measured around pit power and the drone saved wrong TX power walls. The drone now switches pit off when a calibration starts and back on when it ends. **Repeat any calibration you ran on a v0.16 drone** after updating to v0.16.1.

GS and drone stay compatible with v0.16, v0.15 and v0.14 (RC 18, same parameter table), and a v0.16.1 ground station updates the drone by itself.

The fix has host tests only (mabur host suite, with a test that fails without it); a calibration was not run with it, since the bench is too close to the ground station for one. Not flown.
